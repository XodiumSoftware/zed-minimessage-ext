# Guide

## Purpose

This guide exists to help anyone get started with this template. Because this is a template, every file that was copied from the original project still contains placeholders and references that must be replaced before the new project is ready for use.

Before you start developing, review every file and replace all placeholders (for example `<repo>`, `<Project Name>`, `<project_number>`, and any other template markers) with the actual values for the new project.
